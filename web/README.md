# VinyLink — frontend

Frontend de la tienda hecho con Astro (SSR con `@astrojs/node`) e islas de React.
Consulta el [README principal](../README.md) para la descripción completa.

| Comando | Acción |
| :-- | :-- |
| `npm install` | Instala dependencias |
| `npm run dev` | Servidor de desarrollo en `http://localhost:4321` |
| `npm run build` | Compila a `./dist/` |
| `npm run preview` | Sirve la compilación localmente |

Variable de entorno (`.env`): `GRAPHQL_URL`, URL del backend GraphQL
(por defecto `http://localhost:4000/`).
